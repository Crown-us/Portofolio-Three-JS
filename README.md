## 🚀 Memulai (Local Setup)

Ikuti langkah-langkah ini untuk menjalankan proyek di komputer lokal kamu:

1.  **Clone repositori ini:**
    ```bash
    git clone [https://github.com/Crown-us/Portofolio-Three-JS.git](https://github.com/Crown-us/Portofolio-Three-JS.git)
    ```
2.  **Masuk ke direktori proyek:**
    ```bash
    cd Portofolio-Three-JS
    ```
3.  **Instal dependensi:**
    ```bash
    npm install
    ```
4.  **Jalankan server pengembangan:**
    ```bash
    npm run dev
    ```
5.  Buka `http://localhost:5173` di browser kamu.
    
    http://googleusercontent.com/image_generation_content/7

`
